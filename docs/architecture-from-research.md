# 广泛调查如何约束 Vocariri 架构

2026-09-25。本文是架构决策草案和实施缺口清单，不是已实现功能说明。用户再次明确：收集 500–800 种文字 PV 形式，是为了检验架构的通用性。模板数量和架构覆盖需要分别验收。

现有 v2 已把歌词打点与视觉实例分开，但核心仍以仿射文字动画为主。继续添加预设不能补齐遮罩、层级、时变关系、字形变形和渲染依赖。需要先把这些能力的边界写清，再用不同来源和不同机制的样本反复检验。

## 核心表示的边界

2026-10-01 的拉格列车局部原帧复核补充了逐属性继承的反例：灰带转斜时，凹框和字身仍近似保持屏幕朝向。根席旧稿误把凹框也写成转斜，独立席指出后已另存勘误。这个关系要求位置参照、字形朝向、尺寸、裁切和相机作用范围分别表达；不能由一个父节点或排版组自动决定全部属性。原作是否用了父子节点、逆向旋转或相机仍未知。

提案需要明确参照点怎样通过完整变换映射，字形基底在哪个空间规定，以及非均匀缩放、反射、切变和不可逆矩阵怎样处理。只加 `inheritRotation=false` 还不足以定义这些情况。解除关系时匹配完整世界仿射矩阵，在局部几何不变且两侧极限连续时，可保持全部固定字形局部点的世界C0；只匹配anchor则只保证该点。若声明C1，还需指定属性与世界或屏幕空间，并在屏幕空间计入相机导数。奇异父变换使逆矩阵构造不可用，非退化二维目标不可表示，兼容退化目标可能多解；数学不兼容与求值器不支持须分别报告。副影、旧句与新字则各自保有显示区间、材质和退场选择。相邻片段可以延续某个母题，同时让其他层显式切换，不强制所有层做形状变形。

这些要求已记录为四个本地研究设计案例，区分观察、原创可编辑做法、歌词情感的条件建议及待验证项。它们尚未进入运行时或产生渲染模板，形式/模板验收增量仍为0/0。原帧和操作回执保留在研究证据目录，开源材料只提升经复核的设计规则与实现。

2026-10-02 的[独立修订回读](../research/reviews/lagtrain-contract-r2-delta-independent-20261002-r1/REVIEW.md)已关闭这份局部提案的三项修句问题，包与文字检查12/12、纯代数边例5/5。它确认参照节点是原创重建选择、奇异父变换需要区分目标是否退化、完整矩阵与仅anchor匹配的连续性保证不同。这个结论仅针对表示提案，没有运行时或AE渲染接受。

同日 INTERNET OVERDOSE 的[六张原帧独立复核](../research/reviews/overdose-c-visual-20261002-r2/REVIEW.md)补充了材质关系的反例。n3550的横框是黑描边配小黑字，内部仍见场景和人物；初稿写成“黑底白字条”会改变遮挡结果。工程必须把框路径、描边、填充、文字外观与层序分开，空心框不能从“字幕条”用途标签推导出不透明底板。n3559的同一行中，左中部字形呈矩形分块，末端“な”仍有圆顺曲线，需要允许按任意字形集合覆盖材质或几何做法，同时保留共享行排版和语义归属。这些观察不确定原作字形路径、字体名、节点图或着色器，也不要求所有实现都使用同一种网格化方式。

六帧还支持巨字、小字、横框和局部清空作为分别可编辑的对象。被边缘裁掉的首字继续记为unknown；未听音频时，不能把猜测的完整词义转成整曲编排依据。自动选择需要同时读取“可见细节”“条件性歌词/情绪建议”和“尚未验证的阅读/导出限制”，可以采用、修改或拒绝建议。美术规则是开放组合与创作线索，不能成为Agent能生成哪些效果的封闭列表。研究复核继续保留独立形式、艺术变体和实际渲染模板的分别计数，本次没有新增已验收形式或模板。

根席已将上述视觉修正和12处读图PTS误写存成[独立勘误层](../research/reviews/overdose-r1-correction-20261002-r3/CORRECTIONS.json)。勘误保留每条旧值、正确整数源PTS和依据，未改原包。模型推理记录与额外API请求记录分开，跨作品去重判断恢复为unknown；这些修正不代表原包全项验收。

[ART188的三个原始静帧](../research/reviews/art188-three-stills-20261002-r1/OBSERVATIONS.json)分别留下多色轮廓、白面像素式拉丁字及人物重复拼贴的观察。它们提示效果需要声明作用范围：一个颜色扰动可以作用于字形外观、某组人物图像或整幅合成，三者会得到不同的遮挡和阅读结果。文字材质、人物实例阵列、画面边框、噪声相位与摄像机不能被一个“glitch模板”整体锁住。分开的资源和实例可以共享主题，再按对象覆盖；模板保存一种可改的组合，外部Coding Agent仍能增加节点、替换算法和调整作用范围。

静帧中的厚暗边可供原创2D偏移轮廓或平面挤出效果参考，不能据此断定原作用了3D。人物阵列与倒置拼贴只进入场景记录；其中可辨认的ANGEL字样另记文字外观。歌词是否适合过载、断裂或宣言式强调，需要结合实际歌词与音乐判断，未听音频的建议保持条件性。三张图没有给出连续曲线、入退场准确边界或可用渲染模板，后续原帧复核和实作评审仍须完成。

建议采用分层表示，保留当前 v2 的读取能力。新版本号和最终字段在原型验证后确定，本文不把它们写成已经可用的 API。

1. **歌词与音乐时间。** 保存原文、词/字/音节、稳定 ID、人工打点、明确的空白。音乐段落和情绪标注另存，可附来源与不确定性。重复显示不会复制或改坏打点。排版字形与语言单元建立多对多映射，容纳连字、假名注音、装饰文字和故意拆字；视觉节点不必都有 `tokenId`。
2. **素材与派生关系。** 图片、视频、字体、矢量路径、音频是资源。描述、主体区域、锚点、遮罩、头发分层、网格和骨骼可关联到资源；原件保持不变。提取、分割、变形产生可编辑的派生资源并记录依赖。角色、底图是用途标记，不是封闭的对象类型。3D/MMD 视频可以成为合成输入，不要求核心自行运行 3D 舞蹈引擎。
3. **场景与合成。** 文本、字形、形状、图像、视频、组、遮罩、效果具有稳定节点 ID、明确端口和顺序。变换层级与合成依赖分开：层级回答“跟谁动”，合成回答“谁遮谁、先做哪个效果”。2D/2.5D 是默认路径，额外能力通过模块接入。模板是这些对象的可展开组合，展开后每个细节仍可修改。
4. **时间与关系。** 工程时间、镜头局部时间、素材时间分别映射，支持停格、倒放和变速。选择器可以按字、词、行、任意分组或稳定 ID 批量作用。绑定有生效区间、坐标空间和解除策略；解除时可以保持画面位置，也可以显式跳变。组的枢轴与摄像机所属范围必须明确。多条曲线同时写同一属性时，组合顺序、加法/覆盖等规则必须可读，不能由数组碰巧先后决定。
5. **渲染与导出。** 在指定时间求值的结果由共享核心定义；GUI、CLI、缓存和 AE 使用同一语义。扩展声明资源、空间边界、时间依赖及导出能力。AE 可以原生表达、烘焙关键帧、使用代理媒体或暂不支持的部分须逐项列出，用户项目仍保留原始可编辑结构。

有状态效果也必须可重复渲染。例如噪声绑定种子与时间；弹簧或骨骼动态声明初始化、预滚动和检查点。随机拖到某一帧、顺播到该帧以及导出该帧应得到一致结果。无法局部求值的扩展可以声明需要整段重算，不能返回看似有效的旧缓存。

## 连续性怎样成为可执行约束

“自动衔接”需要知道哪些对象应连续、哪些可以变化。边界契约应逐属性描述位置、速度、大小、角度、透明度、遮罩、噪声相位及摄像机所有权。连续可以是端点值相同（C0）、速度也相同（C1），也可以是遮挡期间完成替换，或明确硬切。不能给所有效果统一套一条平滑曲线。

例如，圆头条完全遮住画面后，下面的镜头允许切换；条本身的运动仍要连续。这需要分别评价前景转场与后景镜头。字体换行或路径拓扑变化不一定存在合理的自动插值，应允许指定对应关系或显式切换。约束冲突时提供可定位的结果，外部 Agent 可以批量修复和重跑，既有整曲生成授权不因此变成逐项人工确认。

摄像机覆盖以整段运动包络评估，计入旋转、视差、模糊/位移的采样边缘、透明洞和主体保护区。现有 `coverTransform` 的逐帧矩形覆盖仅解决部分几何露边；它不能保证构图，也可能导致呼吸式缩放。不能据此声称底图问题已解决。

## 接下来用哪些反例检验通用性

这些是研究与产品验收题，不是新增的“已观察模板”。除前三项之外，依据主要是用户要求或尚待核实的机制类别。

| 验收题 | 要检验的能力 | 当前依据 |
|---|---|---|
| 两句重叠、同字回声、分组超调、前景跨句遮挡 | 多实例、独立组、共享转场 | 用户需求及 TEMP-REVIEW-001/002 |
| 卡片离开而字留下，解除后继续独立运动 | 时变绑定、世界/局部坐标 | TEMP-REVIEW-003；具体实现为设计提案 |
| 一句话沿曲线排列，部分字变形后重新成句 | 字形映射、路径、拓扑和选择器 | 本轮广泛搜索方向，待取得充分动作证据 |
| 手写笔画逐步出现、描边/填充顺序变化 | 路径区段、遮罩、样式合成 | 本轮搜索方向，待证据 |
| glitch、位移、残影跨镜头保持相位 | 效果顺序、采样域、时间依赖 | 用户要求；具体案例待核实 |
| 人物头发局部变形、身体上下摆动、文字绕开主体 | 派生素材、骨骼/网格、保护区 | 用户要求；不能由静态人物图推断绑骨方式 |
| 为 MMD 镜头追加文字，背景与屏幕空间文字分别运动 | 视频时间映射、相机空间、遮挡 | 用户要求；MMD 作为场景证据单列 |
| 一首歌统一视觉主题，副歌变化而动机可辨，桥段留白 | 段落级编排、主题资源、节奏密度 | 用户要求；需听音与整段成片评审 |
| 更换歌词或字体后仍可读、不意外裁字 | 文本 shaping、度量、布局约束与重排 | 产品要求；不能只测原样例字符串 |
| 改一个遮罩，局部 AE 缓存与最终工程同步 | 依赖失效、转场余量、代理与原工程一致性 | 用户要求；实际 AE 渲染尚待验证 |
| 任意陌生效果由外部 Coding Agent 实现 | 开放代码模块、检查/导出接口、项目迁移 | 用户要求；预设枚举不得成为扩展边界 |

每轮同时看布局、几何、字形、合成、时间、相机、素材、声音和扩展路径。主动找现有表示失败的案例。颜色替换只增加实例，不自动增加机制；MMD 场景、教程 UI、广告字幕条保留分类与用途。教程中真正演示的字形/合成机制仍可用作研究资料，不因来源是教程而全部丢弃。

研究记录需要新增：来源与区间、证据层级、作用对象、可见时序关系、所需能力、现有表示是否足够、需要的扩展、重建提案、最小反例、未解决项。调查以保留广度为前提；这些字段用于发现缺口，不用于把陌生形式过滤掉。500–800 形式目标和至少 1000 个可用模板/变体目标继续保留。

## 界面、Agent 和低成本生成

用户随后明确要求同时研究艺术字体设计 pattern，并加入 INTERNET OVERDOSE。因此工程需要可复用的美术规则资源：字形/字体与回退、描边与填充、纹理、调色、间距、层级、装饰和主体关系均应能单独编辑，并能在整曲共享或局部覆盖。字体与排版变化会使几何、遮罩和缓存失效，需要纳入依赖计算。原作字体名未知时保留外观描述，不能用猜测名称锁死实现。设计 recipe 可以表达“人物夹在上下两条大标题之间，用多层描边维持识别”等关系，但文字、配色与素材都可替换，不能只存一张参考图。

艺术 pattern、运动形式和架构能力分别记账，互相引用。字体或颜色变化未必构成新运动机制，却可能是需要独立视觉评审的风格变体。每条艺术记录至少包含实际画面细节、审美解释、可复用规则、变化空间与失败条件；更换歌词、脚本或字号后要复查轮廓、留白和阅读顺序。有意设计成窗口、聊天框和像素界面的 PV 画面属于美术内容，不能因为“像软件 UI”而作为教程界面丢弃。

Tauri 界面保留项目/对话/工作区布局。主时间轴区分唱词打点、视觉实例、跨镜头转场；选择任意对象后能看到属性、关系和依赖。批量编辑通过选择器完成，不能要求每句只能占一条互斥轨道。素材入口统一管理资源和派生结果。组件库负责一致的交互与可访问性，不能替代这些结构设计。

CLI 提供可检查的工程读写、局部选择、补丁、验证、取样、预览、导出和能力查询。外部 Coding Agent 可改模板、节点代码、布局器和渲染/导出实现；声明式图提供常用路径，开放代码承接新能力。未知模块数据应原样保存并报告缺少执行能力，不能静默删掉。用户选定的创作模块可以执行，打开陌生工程本身不代表执行其任意代码。

整曲生成可由外部 Agent 一次组织段落、主题和镜头，再落成可重复渲染的工程。后续局部自然语言修改产生明确差异，只使受影响区间和依赖失效；无需每帧、每次播放都调用模型。可复用子图、样式资源、结构化检查结果和小范围参考片减少上下文消耗；完整源代码始终是扩展入口。

参考录屏分析同时保留全景与动作短窗口，记录真实 FPS、输入尺寸和源时间映射。长镜头用于判断构图与关系，短窗口用于辨认遮挡、缩放与进入顺序。模型输出保留推理并标明不确定性；检查失败可自动补采或重做，不把不准的坐标包装成精确关键帧。

## 实施顺序和当前限度

第 09 轮静帧复核补充三个具体反例。INTERNET OVERDOSE 的大字、小字与横线需要可分别调整又相互对齐的组合，不能把整句锁成一个字号；另一片段将汉字与假名拆成不同大小和方向的组，歌词阅读顺序、唱词时间与视觉位置/出现顺序必须分别保存。人物保护区也应表达创作意图：有些镜头故意让主词横过人物，不能由统一的“绝不遮脸”规则否决。可选的硬约束、软约束和明确允许遮挡应在工程里可检查。

参考证据同样需要明确身份：原视频、原生帧、缩放 JPEG 和美术 PNG 分别持有文件哈希、派生步骤、整数 PTS 和时间基准。相同画面可能连续保持多帧，图片哈希不能反推出唯一时点。新采样器已给未来提取补源 PTS 映射；旧图保持原样，旧采样格时间不能无条件用于打点或关键帧。详见 `research/reviews/context-review-09.json`。这些是架构要求与采样修正，尚未实现新的工程图结构。

先随调查持续维护覆盖表，完成节点、时间、合成和模块边界的反例设计；再实现一个能同时容纳重叠文字、跨镜头遮挡、绑定解除和图片派生节点的贯通原型。它必须共享预览/CLI/导出语义，迁移旧工程，并在陌生样本上复核。随后补齐多轨 GUI、AE 区间缓存和整曲生成工作流。

目前未实现上述完整图结构。已有核心测试通过只覆盖其已实现范围，完整 UI 录屏测试仍有空数据失败，原生 AE 视觉一致性未验收。通用表达能力和商业审美是两项检查：前者需要机制覆盖与反例，后者需要真实片段、完整歌曲、可读性、情绪节奏及制作人员评审。任何一项都不能用候选计数代替。


## 2026-10-04：笔画、字形材料与路径排版的有限补充

两段教程的原帧复核补充了不同的控制对象。白色手写示范中，已有 T 的竖笔仍在延长时，旁边已出现下一笔的墨点；后来 TEXT 成立，右侧开始另一组小写笔画。字的唱词时间、笔段的显现进度和整词布局因此需要独立保存，笔段可以重叠。不能把手写效果限制成“上一个字完全画完才允许下一个字进入”。原工程是否用了字体、路径或贴图遮罩仍未知。Earth 示范支持逐字沿弧排列、各自跟随局部切线；所看窗口的合成时间固定，不能用鼠标和选框变化证明字在沿弧运动。曲线弧长、shaping 后的 advance、逐字朝向/修正、整组变换和时间映射应分别可编辑。证据及适用限制见 [教程有限复核](../research/reviews/batch19-reuse-independent-20261004-r1/REVIEW.json)。

ART188 的独立复核又否定了几项过强的简化。ANGEL 跨画面并裁切边缘；浅色面、细彩色边和厚暗色偏移轮廓可分别设计，像阶梯的外观不能自动解释为独立条纹遮罩。文字已消失后才出现所看的亮块洗白，两者的显示寿命和触发次序要分开。相似的 glitch 不证明原片只有一个全局效果，也不证明换镜头时噪声相位连续。工程应声明处理范围、采样域、种子和时间原点，并允许背景受扰动而前景字幕保持清晰。字体身份、原始层图、相机与 AE 能力仍未核实；2D 配方是原创方案，未渲染。适用性可以包含真诚的亲昵、人工 persona、反讽或不适，需结合实际歌词和声画判断，不能只从爱心、霓虹和歌名生成硬情绪标签。见 [14 项纠正与 3 个原创方案](../research/reviews/art188-r3-visual-correction-20261004-r1/CORRECTIONS.json)。

这些补充是表达能力与视觉设计的证据，不增加已验收形式或成品模板计数。新三来源比较任务已实际发给 Qwen，用来继续检验文字、场景、材料和相邻镜头关系；目录不会把调查限定在以上教程或 INTERNET OVERDOSE。
