Retrieved 2026-09-24 UTC from public GitHub and the official npm registry. The raw bytes and acquisition evidence are in [`cache/`]([project root]/research/mechanics/cache) and [`acquisition.jsonl`]([project root]/research/mechanics/acquisition.jsonl). ## What the sources establish

The strongest concrete source family here is Animate.css 4.1.1: independent CSS keyframe templates with named transforms, opacity changes, easing, and a shared duration/fill policy. Remotion's public `BetaText` example adds a frame-indexed, spring-driven kinetic text treatment: a repeated outlined word band enters in alternating directions, scales, and fades. Its easing visualizer is a useful curve-inspection tool, not a lyric-video design. These are reusable motion primitives and implementation examples. No complete VOCALOID PV, artist-specific composition, or finished lyric-video template was inspected; none of the entries below should be treated as a complete design form.

## Continuity and production rules derived from inspection

1. Track a pose as a vector, not only a screen point: position, rotation, scale, opacity, pivot/transform origin, clipping, and text layout/baseline all affect the visible handoff.
2. For a seamless same-object handoff, set the next clip's first pose equal to the previous clip's last pose. If the movement continues through the boundary, also match velocity (direction and magnitude); if it stops, decelerate to zero and hold. A neutral keyframe is useful only if the next layer actually begins neutral.
3. Preserve a fixed lyric box while animating glyph appearance. Reserve travel/rotation/squash bounds in advance so a visual transform cannot trigger line wrapping or collide with another lyric.
4. Treat overshoot as authored travel beyond the target. Either budget enough time to return to the target and settle, explicitly clamp it, or choose a cut that conceals the return. Remotion's unclamped spring example and Animate.css's multi-rebound keyframes make this tradeoff concrete.
5. Use motion hierarchy: a stable readable line, one prominent word-level accent, and at most a restrained supporting layer is easier to read than several independent effects competing at once. The repeated Remotion word band is a deliberately dense special treatment, not a default for every verse.
6. Synchronize the start to an audible lyric/syllable or beat, but leave enough clean exposure to read the text. A keyframe template contains no vocal alignment; timing must come from the song and the chosen vocal/syllable boundaries.

## Export feasibility and reuse notes

CSS keyframes are straightforward to reproduce as named paths and per-keyframe values, but their animation duration, fill mode, and repeat behavior come from shared styles. Animate.css sets a default one-second duration in `source/_vars.css` lines 1–5; its shared `source/_base.css` lines 1–4 sets `animation-fill-mode: both`, lines 42–56 provide speed multipliers, and lines 58–67 reduce animation to 1ms under reduced-motion/print. If reproducing only a keyframe file, bring these surrounding rules into account or choose explicit per-clip values. Browser rendering can be captured frame by frame; an NLE/AE project would normally need the curves and transforms re-keyed, or a rendered alpha sequence. None of the inspected CSS is a finished video timeline.

Remotion code is explicitly indexed by frame and FPS, making its easing and spring movement reproducible in a deterministic renderer. Its React implementation is not itself a native Premiere/After Effects template. Motion Canvas repository access was successful for README and a one-second static scene example, but not enough relevant motion source was obtained to catalogue it. The failed raw-source attempts are preserved in the ledger; no claim about Motion Canvas motion forms is made.

Animate.css 4.1.1 metadata identifies MIT licensing and its package includes the MIT notice (copyright Daniel Eden, 2020). The inspected Motion Canvas license file is MIT (copyright motion-canvas, 2022). The Remotion license request timed out, so the terms for the inspected Remotion example have not been verified. The catalogue is analytical and quotes parameters rather than redistributing source; check each repository's current license before copying code or assets.
