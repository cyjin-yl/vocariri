# Continuation plan: 500–800 distinct segments

The target applies to 500–800 distinct motion/effect forms across public PVs, animation templates, tutorials, and editable project examples, not titles, search results, metadata rows, or parameter-only variants. A video segment is one temporally bounded interval whose composition or motion behavior can be annotated. If a transition starts a different effect grammar, split it; if only the camera crop or a parameter changes while the same operation continues, retain one form and record the variant. Keep source occurrence and reusable form identity separate. Deduplicate by canonical video identity plus interval for video evidence, and by effect/form fingerprint across templates and project examples.

## Access recovery

1. Resume only when public HTTP access is available or an authorized public-source acquisition route exists. Do not reuse credentials, browser state, private caches, or platform bypasses. Keep redirects disabled and response limits enabled.
2. Resume from the acquisition ledger. Do not retry the failed endpoints in a loop. Use one controlled probe per newly available route and record the outcome.
3. Discover examples from public catalogs, creator/video pages, open animation-template libraries, tutorials, and documented editable projects. Save each retrieved source response as a cache object and ledger entry before adding a candidate. Track source kind and whether it documents a reusable form or only shows an occurrence.
4. Obtain lawful public frame evidence (platform-provided public preview/keyframes or a locally inspectable public video stream without bypassing access controls). For tutorials/templates, inspect rendered demonstrations and inspect project structures only when publicly available without access controls. If only a thumbnail is available, annotate it as a still and do not claim motion or timecodes.

## Sampling and review

- Distribute samples across public video works, template collections, tutorials, and editable examples. Avoid letting one creator/library dominate; report actual source and creator distribution. The names in the request are aesthetic examples only, not corpus filters. Retain diversity in era, visual density, typography role, and transition mechanism.
- For each candidate, record source identity/kind, whether evidence is an occurrence or reusable form, observed start/end when applicable, evidence kind and retrieval time, SHA-256 for cached evidence, visual layers, typography behavior, motion, transition-in/out, musical trigger only if synchronized evidence supports it, variant parameters, and unknowns.
- Frame-inspected means actual frame bytes were opened and visually checked at the recorded time. Motion-verified requires temporal comparison or a continuously inspected interval that demonstrates change. Reviewed requires a separate annotation pass; never auto-promote from metadata.
- Have reviewers independently label a stratified 10% subset. Resolve disagreements on segment boundaries and effect/transition labels before scaling. Track inter-review agreement and preserve reject/uncertain outcomes.
- Keep downloaded originals or source-derived images only in `cache/` as research evidence. Do not redistribute them or reuse them as editor templates. Keep only low-resolution, policy-permitted evidence needed for reproducibility.

## Scale and stop conditions

Track five video evidence counts separately: discovered videos, metadata-only candidates, frame-inspected segments, motion-verified segments, and reviewed samples. Separately count discovered non-video sources, source-inspected forms, distinct forms, and parameter variants collapsed. Also track works/producers/libraries represented, duplicates removed, inaccessible candidates, and category gaps. Start with batches of 100 reviewed forms to refine the ontology; scale toward 500–800 reviewed distinct forms only after deduplication rules and inter-review agreement are stable. If access is blocked, stop acquisition, retain the exact failed endpoint and last successful offset/page, and report the counts reached at each evidence stage. Never extrapolate sample counts from candidate counts.

Original media is a research cache, not distributable template material. Share only annotations, source links, and permitted low-resolution evidence derivatives after rights and platform terms are checked.
